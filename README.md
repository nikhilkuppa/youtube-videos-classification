## Architecture

```
web_app/
├── backend/
│   └── api.py               # Flask API server - serves precomputed data,
│                             # no per-request TSV parsing
├── frontend/
│   ├── index.html          # Main HTML interface
│   └── app.js              # Canvas-based visualization engine
├── build_data.py            # One-time offline build: joins t-SNE metadata
│                             # with the unified taxonomy, assigns fixed
│                             # category colors, writes data/precomputed/
├── data/
│   ├── tsne_metadata/
│   │   ├── format/metadata_format.tsv    # ~130k videos, t-SNE coords + info
│   │   └── content/metadata_content.tsv  # ~140k videos, t-SNE coords + info
│   └── precomputed/         # generated by build_data.py - committed, served as-is
│       ├── {content,format}.bin              # packed binary coordinates
│       ├── {content,format}_categories.json  # fixed color palette + legend
│       └── {content,format}_meta.json.gz     # per-video metadata lookup
├── .python-version         # Python 3.11.0 (used by Render)
└── requirements.txt        # Python dependencies
```

Category colors/names come from `taxonomy/outputs/master_retagged.tsv` (the
unified ISCED-F + NE taxonomy built in the sibling `youtube_project` repo),
not the older `edu_content_map.tsv` / `content-map-with-unesco.tsv` /
`format-map.tsv` files (kept here only for historical reference).

## Quick Start

```bash
cd web_app
bash run.sh
```

## Step-by-step Run

### 1. Install Dependencies

```bash
cd web_app
pip install -r requirements.txt
```

### 2. Build the precomputed data (run once, or whenever classifications/taxonomy change)

```bash
cd web_app
python build_data.py
# or, if taxonomy/outputs/master_retagged.tsv lives somewhere else:
python build_data.py --master-retagged /path/to/master_retagged.tsv
```

This reads `data/tsne_metadata/{content,format}/metadata_*.tsv` (t-SNE
coordinates, already computed) plus `master_retagged.tsv` (clean category
labels) and writes `data/precomputed/`, which is what the API actually
serves. Commit `data/precomputed/` so a fresh deploy doesn't need access to
`master_retagged.tsv` at all.

## Running the Application

### Development Mode

```bash
cd web_app
python backend/api.py
```

Then open your browser to: `http://localhost:5000`

### Production Mode (with Gunicorn)

```bash
cd web_app
gunicorn -w 4 -b 0.0.0.0:5000 backend.api:app
```

### Cloud Platform (Render)

Deployment is configured via `render.yaml` at the repo root:
- `rootDir` is set to `./web_app`
- Python version is pinned via `web_app/.python-version`
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn --workers ${WEB_CONCURRENCY:-3} --timeout 120 --bind 0.0.0.0:$PORT backend.api:app`

Boot no longer parses the ~50MB TSVs (that only happens once, offline, in
`build_data.py`), so it's safe to run multiple workers.
